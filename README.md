# Velixo Workbook Inspector

This is an UNOFFICIAL Tool, any usage of this is at your own risk, files are backed up but please manually review files after processing.

Single HTML (local, NO AI looks at your file, no uploads to any server, can be used offline) 

Inspect Excel workbooks (.xlsx/.xlsm/.xltx/.xltm) for Velixo-specific issues and general Excel limits / causes of slow workbooks.

Optional: Share/Clean (similar to native Velixo Snapshot function).

To use download and open `workbook-inspector.html` in a browser.
