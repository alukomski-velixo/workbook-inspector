# Velixo Workbook Inspector

Single-file HTML tool that inspects Excel workbooks (.xlsx/.xlsm/.xltx/.xltm, .xlsb package-level only) for Velixo-specific issues, Excel limits and causes of slow workbooks, and can produce cleaned/share copies. Runs entirely in the browser; files are never uploaded.

Open `workbook-inspector.html` in a browser, or use the claude.ai artifact version.
